# Goodwork

Goodwork is a responsive landing page for a team-workspace concept. It introduces a calmer way to plan projects, collaborate, organize tasks, and celebrate progress.

## Features

- Dark hero section with clear calls to action and a team photo
- Four image-backed feature cards describing the product
- Brand quote section and closing call to action
- Responsive layout for desktop, tablet, and mobile screens
- Accessible page structure, descriptive image text, and reduced-motion support

## Preview locally

No build tools or package installation are required.

1. Download or clone the repository.
2. Open `index.html` in a web browser.

The page loads its font from Google Fonts and its photos from Unsplash, so an internet connection is needed to display those assets.

## Project files

- `index.html` — page content and structure
- `index.css` — layout, colors, typography, responsive styles, and interactions

## Customization

Edit the copy and image URLs in `index.html`. Adjust the brand colors, typography, and responsive styles in `index.css`.
